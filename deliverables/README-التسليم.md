## النتيجة في سطور

التشغيل التأكيدي على 13 عرضاً من 2014 جرى مرة واحدة على الشيفرة المجمَّدة. وأُعيد حساب أحكامه بشيفرة منفصلة في مراجعة آلية بدور «الزميل الباحث» نفّذتها أداة ذكاء اصطناعي، وهي الأداة نفسها التي كتبت خط التجارب، فلا يُعدّ ذلك تحققاً مستقلاً من شخص:

| الفرضية | الحكم |
|---|---|
| H1: الهجين السلوكي مقابل الشعبية الآنية | غير حاسمة: لا يكشف التصميم بقوة 80% أثراً أصغر من 0.0375؛ والفاصل يستبعد إضافة تزيد على 0.0204 بوحدة العرض (0.043 بوحدة المقرر) |
| H2-أ: ترجيح الإشارة السلوكية في WRMF | مؤكَّدة، والفرق موجب في 13 من 13 عرضاً |
| H3: GRU-lite مقابل الجيران على السلال | مدحوضة للتفوق |
| H4-أ: ملامح السلوك في التنبؤ بالتعثر | مدحوضة عملياً: أثر موجب ودال لكنه دون العتبة العملية |

## تنبيهات إلزامية قبل الإيداع

1. **الاسم اللاتيني:** طابِق التهجئة «Kinan Mohammad Karhali» في صفحة العنوان الإنكليزية مع سجل الجامعة.
2. **افتح الأطروحة في Microsoft Word وحدّث الحقول** (فهرس المحتويات والأشكال والجداول والترقيم)، ثم تحقق من المعادلات والاتجاه والخطوط. عدد الصفحات يتغير بعد التحديث (نحو 227–243 في معاينة LibreOffice التي لا تعرض المعادلات). وطبّق قالب الجامعة الرسمي إن وُجد.
3. **المرجع [22] (Kumar وآخرون، 2022):** يُستشهد به وثيقةً على الوب لأن وعاءه لم يُتحقق منه. خطة البحث الأصلية تذكر له DOI من Springer هو `10.1007/978-981-99-0085-5_58`، ولم يُحل في بيئة العمل. تحقق منه، فإن صح فاستبدل المرجع بالصيغة الكاملة واحذف ملاحظة «لم يُتحقق من وعائها».
4. **المرجع [26] (Chandna وKumar، 2026):** أُغفل الـDOI المطبوع في نسخة الناشر (`10.70917/ijcisim-2026-5377`) لأنه لم يُتحقق من تسجيله. أضفه إن حُلّ.
5. **الإهداء** محذوف عمداً، فأضفه إن شئت.
6. **النزاهة الأكاديمية والإفصاح (شرط قبل المنح):** أنت مؤلف الرسالة المسؤول عنها، فاقرأ النص كاملاً وتبنَّه. أجرِ فحص الاستلال المعتمد في الجامعة. وأكمل مسودة الإفصاح عن أداة الذكاء الاصطناعي (`docs/defense/disclosure-draft.md`) ووقّعها، وأدرجها في المقدمات بعد مراجعة سياسة الجامعة. واعلم أن محاضر «المشرف» و«الزميل الباحث» في `docs/meetings/` ومحضر المناقشة التجريبية مراجعات محاكاة نفّذتها الأداة، فاعرض قرارات التجميد على المشرف الفعلي د. باسل الخطيب ليعتمدها أو يعدّلها.
7. **مصدر الأرقام:** كل رقم في الرسالة مأخوذ من ملفات `results/`. أرقام الواجهة توضيحية لا يُستشهد بها، وعروض 2014 غير معروضة في الواجهة عمداً.
8. **العرض:** 20 شريحة رئيسية لمدة 15–20 دقيقة، و4 احتياطية للأسئلة. تحقق من الخطوط العربية على جهاز العرض. والأسئلة المتوقعة من اللجنة في `.claude/skills/academic-supervisor-basel-alkhatib/references/defense-questions.md` وفي محاضر `docs/meetings/`.
9. **التقويم البشري (شرط قبل المنح):** أجرِ تقويم الخبراء مع ثلاثة مدرّسين ومقياس SUS مع خمسة متعلمين بالبروتوكول الجاهز (`docs/defense/human-evaluation-protocol.md`)، وأضف نتائجه ملحقاً.
10. **مقارنة scikit-learn (شرط قبل المنح):** شغّل `python3 scripts/posthoc/sklearn_equivalence.py` على حاسوب فيه scikit-learn (لم يُتح تثبيتها في بيئة العمل)، ثم `python3 scripts/thesis/appendix_e.py` وأعد بناء الأطروحة، فيُدرج الجدول في الملحق هـ.
11. **سجل التصويبات:** حالة كل بند من قرار اللجنة في `docs/defense/04-corrections-log.md`.

## إعادة الإنتاج

**اقرأ قبل الأوامر.** الوسم `freeze-03` موجود في نسخة العمل المحلية وحدها، لأن بيئة العمل رفضت دفع الوسوم؛ فلا يوجد في أي نسخة جديدة من المستودع، ويفشل `git checkout freeze-03` عليها. أما الـcommit الموسوم `eb34d6a7ba23f9ff0ecffab8081228c5d6ce94c5` فمدفوع على الفرع، فالانتقال برقمه يعمل دون الوسم. ولم يكن `requirements.txt` موجوداً عند نسخة التجميد، فثبّت الاعتماديات من الفرع الحالي قبل الانتقال إليها. والسكربتات اللاحقة (`scripts/conf2014_provenance.py` و`scripts/posthoc/` و`scripts/thesis/`) أضيفت بعد التجميد، فتُشغَّل من الفرع الحالي.

```bash
# 1) من الفرع الحالي: الاعتماديات والبيانات (data/raw وdata/cache خارج git، فتبقى بعد الانتقال بين النسخ)
git clone https://github.com/kkarhali/rec-eLearning-sys && cd rec-eLearning-sys
git checkout kk_auto_/amazing-planck-wzsemh
python3 -m pip install -r requirements.txt          # الإصدارات المثبتة (Python 3.13)
bash data/download.sh                              # تحميل OULAD والتحقق من MD5 («integrity: PASS»)

# 2) نسخة التجميد برقم الـcommit (لا تحتاج الوسم)
git checkout --detach eb34d6a7ba23f9ff0ecffab8081228c5d6ce94c5
python3 -m src.ml.experiments.reproduce_dev        # إعادة نتائج التطوير 2013 (≈ 50 دقيقة، «مطابق» 36/36 في results/dev2013/repro_diff.md)
git stash push --include-untracked -m repro-freeze03 -- results/    # يحفظ ما كتبه التشغيل ويعيد الشجرة نظيفة

# 3) العودة إلى الفرع الحالي للسكربتات اللاحقة
git checkout kk_auto_/amazing-planck-wzsemh
python3 scripts/conf2014_provenance.py             # بيان منشأ ملفات 2014 المستعملة (44 ملفاً)
python3 scripts/posthoc/a4_1_recentpop_sknn.py     # التحليلات اللاحقة (الملحق هـ)؛ ومعها a4_2_sknn_all.py وa4_3_companion_metrics.py وdefense_stats.py
python3 scripts/posthoc/a5_nonpersonal_weights.py  # الجلسة الثانية (هـ-7 إلى هـ-10)، بالترتيب: a5، a6_personalization_mall.py،
                                                  # a7_delta_sensitivity.py، a8_h3_by_cut.py، a10_selection_loo.py،
                                                  # a11_h3_equal_info.py (≈ 62 د)، a12_symmetric_info.py، ثم a9_inventory.py
python3 scripts/thesis/appendix_e.py                # الملحق هـ من results/posthoc/
```

```bash
git tag -a freeze-03 eb34d6a7ba23f9ff0ecffab8081228c5d6ce94c5 -m "freeze-03"
git push origin freeze-03
git ls-remote --tags origin                         # يجب أن يظهر refs/tags/freeze-03
```
