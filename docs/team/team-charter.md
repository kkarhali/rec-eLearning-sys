# ميثاق الفريق البحثي وتوزيع الأدوار والموديلات

**المشروع:** رسالة ماجستير علوم الوب — «نظام توصية للتعليم الإلكتروني القائم على تحليل سلوك المستخدم»
**قائد البحث (Lead Researcher):** الوكيل الرئيس (Claude Fable 5.1) — يتقمّص دور الباحث الأكاديمي، ينسّق الفرق، يوّلف المخرجات، ويحاور المشرف.

## 1. مبدأ توزيع الموديلات

| قوة الموديل | يُستخدم لـ |
|---|---|
| **Fable** (قائد البحث فقط) | التنسيق العام، التوليف النهائي، الحكم بين الآراء، الرسالة النهائية |
| **Opus** (effort: high) | الحكم الأكاديمي العميق (المشرف)، توليف حالة الفن، تصميم الفرضيات والخوارزميات، المعمارية، هندسة ML، كتابة الأطروحة |
| **Sonnet** (effort: medium/high) | تحليل المراجع ورقةً ورقة، كشف البيانات، المراجعة النقدية (الزميل)، التوثيق التقني، الواجهات، المخططات، العرض التقديمي |
| **Haiku** (effort: medium) | المهام الآلية القابلة للتحقق: فحص بيانات المراجع البيبليوغرافية، فهرسة، لقطات الشاشة، تحويلات الملفات |

القاعدة: **المهمة تحدد الموديل**، لا العكس. لا يُستخدم Fable لغير قائد البحث.

## 3. قواعد التواصل والقرار
1. أي عضو يواجه غموضاً أو تحدياً معقداً يرفعه فوراً إلى المشرف؛ **لا قرارات افتراضية**.
2. المشرف يرد مباشرة ويعقد اجتماعاً عند الحاجة؛ المحاضر في `docs/meetings/`، القرارات الدائمة في `docs/decisions/`.
3. كل مخرج يمر: الزميل الباحث ← تعديلات ← المشرف ← قبول ← إخراج Word في `deliverables/`.
4. لا تواصل مع المستخدم إلا لإشعاره بإنهاء مرحلة وتسليم ملفاتها.
5. الصدق المطلق في النتائج؛ القيود البيئية تُوثَّق لا تُخفى.
