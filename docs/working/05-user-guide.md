## 1. مقدمة

### 1.1 ما هذا النظام

«موصي التعلّم» نظام توصية للتعليم الإلكتروني. يقترح على المتعلم موارد من المقرر الإلكتروني لم يفتحها بعد، ويشرح لماذا اقترحها. ويعرض على المدرّس أو المشرف صورة عامة عن أنماط الانخراط في العرض الدراسي، ومن قد يحتاج إلى متابعة أكبر.

تقوم الواجهة على بيانات منصة OULAD (Open University Learning Analytics Dataset)، وهي بيانات تاريخية منشورة عن مقررات الجامعة المفتوحة البريطانية. كل عرض دراسي (presentation) يحمل رمزاً مثل `FFF_2013J`. توجد 22 عرضاً في البيانات: تسعة منها للتطوير والاختبار الأولي (عروض 2013)، وثلاثة عشر للتأكيد (عروض 2014)، وهذه الأخيرة مقفلة في الواجهة كما سيأتي.

### 1.2 ما الذي يفعله النظام وما الذي لا يفعله

النظام يعمل بنمط **إعادة التشغيل** (Replay). تختار يوماً t داخل العرض، ويحسب النظام **عند اليوم t نفسه** ما كان سيوصي به النموذج المجمَّد، مستعملاً بيانات تقع قبل t أو عند t فقط. لا يرى المستقبل.

| يفعل | لا يفعل |
|---|---|
| يعيد حساب التوصيات لأي يوم t من بيانات تاريخية محفوظة | لا يجمع بيانات حيّة من أي مستخدم |
| يعرض أفضل 10 موارد لم يزرها المتعلم بعد، مع تفسير لكل منها | لا يدرّب النماذج عند الطلب |
| يعرض تاريخ النموذج الذي استُعملت معاملاته | لا يملك تسجيل دخول أو حسابات مستخدمين |
| يعرض للمدرّس العناقيد والملامح ودرجة خطر غير معايَرة | لا يعرض درجة الخطر أو العنقود على المتعلم |
| يعرض أرقام التجربة للتوضيح فقط | لا يعرض مقاييس التقييم ولا يحكم بها على أحد |

وتذكير مهم: **المتعلم في النظام تسجيل تاريخي في البيانات، لا شخص يتصفح الواجهة الآن.** أرقام التسجيل وأسماء الموارد مستعارة من البيانات ولا تعرّف بأحد.

### 1.3 لمن هذا الدليل

يخدم الدليل ثلاثة أدوار، وكل جزء يبدأ بالدور الذي يهمه:

1. **المتعلم:** يقرأ القسم 3 لفهم التوصيات وتفسيراتها.
2. **المدرّس أو المشرف:** يقرأ القسم 4 لفهم لوحة المؤشرات وحدودها الأخلاقية والمنهجية.
3. **مشغّل النظام (الباحث):** يقرأ القسم 2 لتشغيل النظام، ثم القسم 6 للمرجع التقني.

### 1.4 شريط «عرض توضيحي بلا أمان وصول» (D-66)

يظهر في كل صفحات الواجهة، بجوار شارة «إعادة تشغيل على بيانات تاريخية (OULAD) — لا جمع حي»، شريط بعنوان «عرض توضيحي بلا أمان وصول». معناه عملي: النظام تشغيل محلي للعرض والتجربة، **لا توجد مصادقة**، ومن يصل إلى الخادم يرى كل الصفحات. لذلك الربط الافتراضي على 127.0.0.1، ولا يُنشر النظام على شبكة عامة. الخيار `--no-instructor` يخفي لوحة المدرّس ويعطّل مساراتها، لكنه لا يحمي المتعلم من شيء ولا يقوم مقام المصادقة.

### 1.5 المتطلبات

- **Python 3.13** مع الحزم: `numpy` و`pandas` و`starlette` و`uvicorn` و`pydantic`.
- **مترجم TypeScript** (`tsc`) لبناء الواجهة مرة واحدة.
- **مجلدات البيانات والمخرجات:** `data/raw/oulad/` و`data/cache/` و`artifacts/` وملف `results/dev2013/hybrid_frozen.json`. إن غابت، يرد الخادم بخطأ `artifacts_missing` (انظر القسم 2.4).
- **متصفح حديث** يدعم العربية من اليمين إلى اليسار. الواجهة مصممة لتعمل من عرض 360 بكسل فما فوق.

## 2. البدء السريع لمشغّل النظام

الأوامر التالية تفترض أن المستودع في `/home/user/rec-eLearning-sys`. عدّل المسار إن كان موقعك مختلفاً.

### 2.1 الخطوات الأساسية

**الخطوة 1: بناء الواجهة مرة واحدة.**

```bash
cd /home/user/rec-eLearning-sys
bash src/frontend/build.sh
```

يترجم الأمر ملفات TypeScript إلى `src/frontend/dist/js` وينسخ صفحات HTML وCSS وملفات المحاكاة إلى `dist/`. يُعاد تشغيله بعد كل تعديل على الواجهة. مجلد `dist/` مستثنى من git.

**الخطوة 2: تشغيل الخادم مع التسخين.**

```bash
python3 -m src.backend --warm
```

يبدأ الخادم على `http://127.0.0.1:8000` ويخدم الواجهة من `/` وواجهة البرمجة من `/api/`. خيار `--warm` يحسب في الخلفية توصيات اليوم 75 لعرض `FFF_2013J` وتجهيز لقطة المدرّس، فيستغرق ذلك نحو 12 ثانية بعد الإقلاع. بعدها تستجيب الطلبات لهذا اليوم في نحو 10 ملي ثوانٍ.

يمكن التحقق من حالة التسخين بالطلب التالي، وتظهر فيه القيمة `warm.state` (`pending` أو `running` أو `done` أو `failed`):

```bash
curl http://127.0.0.1:8000/api/health
```

**الخطوة 3: فتح المتصفح.**

افتح `http://127.0.0.1:8000/` في المتصفح. تظهر الصفحة الرئيسية، وتجد في شريط التنقل العلوي: الرئيسية، والمتعلم، والمدرّس، وعن النظام.

**الخطوة 4: تشغيل بلا لوحة المدرّس (اختياري).**

```bash
python3 -m src.backend --warm --no-instructor
```

هذا الخيار يجعل مسارات `/api/instructor/*` ترد بالخطأ `instructor_disabled` (رمز 404)، وتصبح صفحة المدرّس 404، وتُخفى روابطها من الواجهة.

تنبيه: هذا **إخفاء وليس حماية**. الروابط تُخفى، ومساراته ترد بخطأ، لكن النظام لا يملك مصادقة أصلاً (D-22 وD-66، انظر القسم 1.4). لا تنشر الخادم على شبكة عامة.

**خيارات أخرى:**

| الخيار | المعنى |
|---|---|
| `--host 127.0.0.1` | عنوان الاستماع. الافتراضي 127.0.0.1 |
| `--port 8001` | المنفذ. الافتراضي 8000 |
| `--warm-presentation BBB_2013J` | العرض الذي يُسخَّن |
| `--warm-days 75,126` | الأيام التي تُسخَّن، مفصولة بفواصل |
| `--log-level debug` | مستوى السجل |

مثال كامل:

```bash
python3 -m src.backend --host 127.0.0.1 --port 8000 --warm --warm-presentation BBB_2013J --warm-days 75,126
```

### 2.2 وضع المحاكاة (بلا خادم)

يمكن عرض الواجهة كاملة دون تشغيل الخادم. تكون الأرقام في هذا الوضع **وهمية** ومُعدّة للعرض فقط، ولا تمثل أي نتيجة من التجربة.

```bash
cd /home/user/rec-eLearning-sys
bash src/frontend/build.sh
python3 -m http.server 8000 -d src/frontend/dist
```

ثم افتح `http://127.0.0.1:8000/`. تُفعَّل المحاكاة تلقائياً إن فشل الطلب `GET /api/health` أو لم يُعِد JSON صالحاً، وتظهر شارة «وضع المحاكاة» في الشريط العلوي. ويمكن فرض الوضع من عنوان الصفحة:

- `?mock=1` لتشغيل المحاكاة (يُحفظ الاختيار في `sessionStorage`).
- `?mock=0` لإلغاء المحاكاة والاتصال بالخادم.

تحمل المحاكاة ملفات JSON بالشكل نفسه الذي يعيده الخادم، فيكفي هذا الوضع لاستعراض الشاشات. ملاحظة: في المحاكاة يُعرض العرض `BBB_2013J`، وتُعاد استعمال بياناته للعرض `FFF_2013J`. العرض `BBB_2014J` مقفل (رمز 409).

### 2.3 لقطات الشاشة

تُلتقط اللقطات بمتصفح حقيقي على خادم حي. الأمر المطلوب بعد تشغيل الخادم بالتسخين:

```bash
NODE_PATH=$(npm root -g) node src/backend/e2e/live-screenshots.js
```

تُحفظ اللقطات في `deliverables/05-user-guide/screenshots/` بالبادئة `live-`. اللقطات الأقدم بالبادئة `0x-` من وضع المحاكاة قديمة ولا يعتمد عليها هذا الدليل.

## 3. دليل المتعلم

صفحة المتعلم تجيب عن سؤال واحد: **ماذا كان سيوصيني به النظام عند اليوم t من هذا المقرر؟** وتجيب عن ثلاثة أسئلة فرعية: لماذا، ومنذ متى، وما الذي تغيّر.

### 3.1 الصفحة الرئيسية

تظهر الصفحة الرئيسية عند فتح الرابط الجذر. في أعلاها عنوان «موصي التعلّم» ووصف قصير، وفي شريط التنقل الشارة المزدوجة «إعادة تشغيل على بيانات تاريخية (OULAD) — لا جمع حي · عرض توضيحي بلا أمان وصول»، ثم شريط أصفر يشرح نمط إعادة التشغيل: البيانات تاريخية من OULAD بلا جمع حي، ولا يُستعمل أي حدث بعد اليوم t، والأرقام للعرض لا للتقييم.

![الشكل 1: الصفحة الرئيسية: اختيار العرض والتسجيل واليوم](deliverables/05-user-guide/screenshots/live-01-home-desktop.png){width=100%}

تنقسم الصفحة إلى ثلاث خطوات مرقّمة:

1. **اختر العرض.** بطاقات للعروض التسعة للتطوير، وبطاقة لعرض 2014 تحمل عبارة «مقفل حتى النشر». تعرض كل بطاقة الرمز، ووصف الوحدة والدورة، وعدد المسجلين، وعدد أيام العرض. العرض المحدَّد يظهر بإطار أخضر.
2. **اختر التسجيل.** حقل بحث برقم الطالب، وقائمة منسدلة بالتسجيلات مرتبة من الأكثر نشاطاً إلى الأقل. الرقم في القائمة هو معرّف التسجيل في البيانات، وليس اسماً.
3. **حرّك اليوم t.** حقل رقمي، وزرّا السابق والتالي، وشريط زمني. بعد الضغط على «افتح واجهة المتعلم» أو «افتح لوحة المدرّس» تنتقل الصفحة بالعرض واليوم المختارين.

### 3.2 شريط الأيام ومعنى العلامات

الشريط الزمني يمثل مدى العرض كله، من اليوم 0 إلى آخر يوم فيه أحداث (في الشكل الحالي 268). **الاتجاه معكوس كما في العربية**: اليوم 0 على اليمين، وآخر يوم على اليسار.

العلامات على الشريط:

- **خطوط رأسية صغيرة (نقاط تنقل سريع):** تبدأ من اليوم 0 بفواصل 14 يوماً، وتُستعمل للتنقل السريع فقط. الحساب يتم دائماً عند اليوم الذي يكتبه المستخدم، لا عند أقرب نقطة.
- **أعمدة خضراء أطول:** قطع النموذج، أي الأيام 70 و126 و182. عندها تتغير المعاملات الثقيلة للنموذج كما سيأتي في القسم 3.6.
- **معينات برتقالية:** مواعيد التقييمات في العرض.
- **المؤشر الدائري:** اليوم المختار حالياً. إن لم يقع على نقطة تنقل تُعرض في الشارة «أقرب نقطة تنقل»، كما في «اليوم 75 · أقرب نقطة تنقل 70».

**التحكم بالشريط:** الأسهم اليمين واليسار تحرّك اليوم، وHome وEnd تنقلان إلى الحدّين، وPageUp وPageDown تقفزان بمقدار أكبر. ويمكن كتابة اليوم في الحقل الرقمي مباشرة.

![الشكل 2: صفحة المتعلم: أفضل 10 موارد وشريط اليوم ونشاطك](deliverables/05-user-guide/screenshots/live-02-learner-desktop.png){width=100%}

### 3.3 شريط السياق

أعلى قائمة التوصيات شريط يلخّص اليوم المحسوب، مثل:

> اليوم 75 (الحساب عند اليوم t نفسه) · الأسبوع 11 · التقييم القادم: TMA بعد 21 يوماً · أيامك النشطة حتى الآن: 94

- **الأسبوع:** رقم الأسبوع الدراسي عند اليوم t.
- **التقييم القادم:** نوع التقييم وعدد الأيام المتبقية حتى موعده.
- **أيامك النشطة حتى الآن:** عدد الأيام التي فيها نشاط للمتعلم حتى اليوم t.

إن كان اليوم المختار على نقطة تنقل فالعبارة «الحساب عند اليوم t نفسه». أما إن اختلفا فتقول العبارة «محسوب عند اليوم N»، وهذا نادر ولا يغيّر شيئاً في طريقة القراءة.

إلى جانب الشريط تظهر شارة **«تاريخ النموذج»**، وهي موضوع القسم 3.6.

### 3.4 قراءة بطاقة التوصية

تحت شريط السياق قائمة بعنوان «أفضل 10 موارد لم تزرها بعد»، وهي مرتبة بدرجة الهجين المجمَّد. كل بطاقة فيها:

- **الرتبة:** رقم داخل دائرة على الطرف.
- **نوع النشاط ومعرّف المورد:** مثلاً «محتوى (oucontent) #716344». نوع النشاط بالعربية كما يصنفه المقرر، والرقم هو معرّف المورد (`id_site`). لأن البيانات مجهولة الهوية، لا توجد عناوين للموارد، فهذا هو الاسم الوحيد المتاح. وتظهر أنواع أخرى مثل «مورد (resource)» و«تعاون (oucollaborate)».
- **الدرجة:** قيمة الترتيب المحسوبة من الهجين، وليست احتمالاً ولا نسبة نجاح. تُعرض بجوار الاسم.
- **الجملة الرئيسية:** جملة قصيرة تفسّر الاقتراح، مثل «شائع لدى متعلمين بنمط مشابه لنمطك».
- **شريط مساهمة المكوّنات:** شريط أفقي ملون يبيّن أي مكوّن أسهم بكم في الدرجة. الأزرق البنفسجي لمكوّن SKNN، والأحمر القرمزي لمكوّن «شعبية الأنماط المشابهة». يظهر المكوّنان بوزنهما في أسفل القائمة.
- **زر «لماذا؟»:** يفتح نافذة التفسير (القسم 3.5).

![الشكل 3: نافذة «لماذا؟» تفصّل مساهمات المكوّنات للمورد المختار](deliverables/05-user-guide/screenshots/live-03-learner-why-desktop.png){width=100%}

أسفل القائمة ملاحظة ثابتة: «لا يظهر للمتعلم أي وسم خطر أو عنقود أو مقارنة بالآخرين».

**خيار «بما فيه ما زرتُه (المهمة B)»:** غير مفعّل افتراضياً، فتظهر الموارد التي لم يزرها المتعلم بعد. عند تفعيله تدخل الموارد التي زارها المتعلم أيضاً في الترتيب. المهمة A هي الافتراضية، وهي التي يبني عليها الهجين فرضياته في الرسالة.

### 3.5 نافذة «لماذا؟»

عند الضغط على «لماذا؟» تفتح لوحة جانبية باسم المورد، مثل «لماذا حتّى محتوى #716329؟». تتضمن اللوحة:

- **الدرجة وطريقة حسابها:** «الدرجة = مجموع (الوزن × الرتبة المطبَّعة)». الوزن ثابت لكل مكوّن في القطع الحالي، والرتبة المطبَّعة قيمة بين 0 و1 تعكس موقع المورد في ترتيب المكوّن، وكلما اقتربت من 1 كان أعلى في ذلك الترتيب.
- **كل مكوّن على حدة:** اسمه (مثل «شعبية الأنماط المشابهة (7)» أو «SKNN (4)»)، ووزنه، وشريط يبيّن مساهمته، ومعادلة صغيرة بالأرقام.
- **الدليل:** سطر يذكر ما استند إليه المكوّن، مثلاً أن المورد استخدمه عدد من المتعلمين في آخر 3 أيام، أو أن مورداً سابقاً في تاريخ المتعلم قريب منه.
- **الجملة الثانوية:** تظهر فقط إن بلغت مساهمة المكوّن الثاني ثلث الدرجة، مثل «يتبع غالباً ما زرتُه مؤخراً».

تُغلق اللوحة بزر × أو بمفتاح Esc، ويعود التركيز إلى زر «لماذا؟» الذي فتحها. فإن أردت فهم مورد آخر، اضغط زر «لماذا؟» في بطاقته.

التفسير **صادق بالبناء**: الجملة مأخوذة من المكوّن ذي المساهمة الأكبر، والمساهمات المعروضة تجمع إلى الدرجة. لكنه يصف كيف حسب النظام الاقتراح، ولا يدّعي أن هذا هو السبب الحقيقي لاختيار المتعلم. ولم يُقيَّم التفسير مع مستخدمين بعد.

### 3.6 شارة «تاريخ النموذج»

الشارة تقول أي **قطع** من قطع النموذج استُعملت معاملاته الثقيلة. القطع الممكنة هي 70 و126 و182، أي أن النموذج دُرّب عندها فقط، ولا يُدرَّب عند كل طلب.

مثال: عند اليوم 75 تظهر «تاريخ النموذج: اليوم 70»، لأن أقرب قطع لا يتجاوز 75 هو 70. هذا يعني أن معاملات المكوّنات الثقيلة (WRMF وGRU-lite) مأخوذة من تدريب اليوم 70، لكن **حالة المتعلم نفسها تُحسب عند اليوم 75**، من تاريخه حتى ذلك اليوم.

تذكّر: «تاريخ النموذج» ليس تاريخ التوصية، والشارة لا تعني أن البيانات أقدم. البيانات حتى اليوم t كاملة.

### 3.7 حالة «قبل أول قطع»

قبل اليوم 70 لا يوجد أي قطع تدريب، فتقول الشارة «تاريخ النموذج: لا قطع بعد»، ويظهر تحتها تنبيه بلون برتقالي: «لا مكوّن ثقيل قبل اليوم 70: أُعيدت معايرة أوزان المكوّنات المتاحة».

![الشكل 4: حالة اليوم 40: لا قطع بعد، والتوصيات من المكوّنات الخفيفة وحدها](deliverables/05-user-guide/screenshots/live-04-learner-before-first-cut-desktop.png){width=100%}

في هذه الحالة تحسب التوصيات من المكوّنات الخفيفة وحدها، وتُعاد معايرة أوزانها لتبلغ الواحد. ويجب قراءة توصيات الأيام الأولى بهذا الاعتبار.

### 3.8 حالة «التسجيل لم يتفاعل بعد مع الكتالوج»

إن لم يكن للمتعلم أي تفاعل مع موارد الكتالوج حتى اليوم t، يُعرض ترتيب غير شخصي مع إشعار. هذه الحالة ممكنة في الأيام الأولى من العرض.

### 3.9 نشاطي في آخر 28 يوماً

في الجانب الأيسر أسفل قائمة التوصيات بطاقة «نشاطي في آخر 28 يوماً حتى اليوم t». تظهر 28 خانة في صفين من 14 خانة:

- **الخانة الداكنة:** يوم فيه نشاط، وكلما كان الأغمق كان النشاط أكبر.
- **الخانة الفاتحة:** يوم فيه نشاط قليل.
- **المسافة الفارغة:** يوم بلا أي نشاط.

تحت الشبكة عدد الأيام النشطة حتى اليوم t، ثم قائمة «آخر ما زرته» بثلاثة موارد مع اليوم الذي زرتها فيه. هذه البطاقة تخص المتعلم وحده، ولا تقارنه بغيره.

### 3.10 ما لا تعرضه صفحة المتعلم

صفحة المتعلم لا تعرض:

- درجة الخطر النسبية، ولا أي وسم أو تقدير يتعلق بالانسحاب أو الفشل.
- العنقود السلوكي الذي ينتمي إليه المتعلم.
- أي مقارنة بالزملاء أو بالمتوسط.
- أي سمة حساسة (الجنس، والإعاقة، والمنطقة، والفئة العمرية، والمستوى التعليمي، وفئة IMD).
- نتائج التقييم النهائية أو أي مقياس من مقاييس التجربة.

هذا قرار تصميم مقصود (D-22 وNFR-09). فالمتعلم لا يحصل على حكم عن نفسه، ولا يعرف أي وسم مرتبط به.

## 4. دليل المدرّس أو المشرف

لوحة المدرّس تعرض العرض كله عند اليوم t: مؤشرات عامة، وعناقيد سلوكية، وتوزيع درجة الخطر، وتغطية التوصيات، وجدولاً بالمتعلمين مرتباً بدرجة الخطر، وملفاً لكل متعلم.

### 4.1 تنبيه قبل البدء

يعرض الشريط الأحمر أعلى الصفحة: «للمدرّس/المشرف فقط: درجة خطر نسبية غير معايَرة من نموذج Logistic L2 ليست حكماً على المتعلم، ولا تظهر في واجهة المتعلم. الأرقام للعرض والتوضيح لا للتقييم (D-49).»

هذا التنبيه ليس تفصيلاً شكلياً. اقرأ الأرقام كلها على هذا الأساس.

![الشكل 5: لوحة المدرّس، الجزء الأول: المؤشرات والعناقيد](deliverables/05-user-guide/screenshots/live-05-instructor-desktop-a.png){width=100%}

### 4.2 تبدأ اللوحة من اليوم 56

لا تعرض لوحة المدرّس بيانات قبل اليوم 56، لأن العناقيد لا تُحسب قبله. إن اخترت يوماً أقدم، تنتقل الواجهة تلقائياً إلى اليوم 56. وتعرض اللوحة درجة الخطر النسبية من أقرب قطع متاح لليوم المختار.

### 4.3 لوحة المؤشرات

خمس بطاقات أعلى الصفحة. الأرقام عند اليوم 75 للعرض `FFF_2013J`:

| البطاقة | المعنى | القيمة عند اليوم 75 |
|---|---|---|
| متعلمون نشطون حتى اليوم 75 | عدد المتعلمين المسجَّلين حتى اليوم t ولم ينسحبوا بعد، وهو الفوج الذي تُحسب عليه الإحصاءات | 1,860 |
| وسيط الأيام النشطة | وسيط عدد الأيام التي فيها نشاط حتى اليوم t | 37 |
| الكتالوج عند اليوم 75 | عدد الموارد المتاحة في الكتالوج حتى اليوم t | 254 مورداً |
| Coverage@10 للتوصيات | نسبة الكتالوج التي ظهرت في قوائم أفضل 10 لأي متعلم | 0.39 |
| درجة الخطر ≥ العتبة (نسبية) | نسبة المتعلمين الذين تجاوزوا عتبة الخطر | 39% |

تحت البطاقة الأخيرة سطر: «درجة نسبية غير معايَرة، للعرض لا للتقييم». والعتبة (0.46) مأخوذة من تقييم Youden على عروض 2013 ومجمّدة، ولا تُعاد معايرتها لكل عرض.

### 4.4 العناقيد السلوكية

قسم العناقيد يجيب عن سؤال: **هل ينقسم المتعلمون إلى مجموعات تتشابه في أنماط نشاطهم؟** ويعرض:

- **لقطة العناقيد:** السطر الأول يذكر «لقطة العناقيد: اليوم 56»، أي أن العناقيد تُحسب مرة عند اليوم 56 وتُطبَّق على ما بعده. وهذا غير اليوم المختار.
- **عدد العناقيد (k):** العدد الذي اختاره النظام لهذه اللقطة.
- **مؤشرات الجودة:** silhouette وDBI وARI. الـsilhouette قريب من الصفر يعني تداخلاً كبيراً بين المجموعات، وDBI أقل أفضل. أما «ARI (ثبات البذور)» فيقيس تطابق التجميع عبر بذور مختلفة لنفس k، وقيمته 1 تعني تطابقاً تاماً.
- **الوسم «عناقيد غير مستقرة»:** يظهر حين لا يستقر التجميع، والسبب مكتوب تحته. الاستقرار يشترط أمرين معاً: ثبات البذور (ARI مرتفع)، وأن يقع k ضمن أفضل اثنين في silhouette وDBI معاً. لذلك قد يظهر ARI = 1 والوسم مع ذلك، لأن الشرط الثاني لم يتحقق. لا تعتمد على عنقود بعينه في هذه الحالة.
- **الحلقة الدائرية:** عدد المتعلمين في كل عنقود.
- **الرسم المبعثر:** إسقاط ثنائي الأبعاد (PCA) للملامح. النقاط الزرقاء مربعات، والخضراء دوائر، والمحوران ليسا مقياسين لشيء محدد بذاته.

لكل عنقود بطاقة فيها اسم ووصف عربي مولَّد من أبرز ملمحين انحرافاً عن المتوسط:

- **«أيام نشطة قليلة · نشاط متقطع»:** 661 متعلماً عند لقطة العناقيد (اليوم 56). أبرز ملمحيه: قلة الأيام النشطة، وانحراف مرتفع في الفجوات بين أيام النشاط.
- **«أيام نشطة كثيرة · نشاط منتظم»:** 1,211 متعلماً. أبرز ملمحيه: كثرة الأيام النشطة، وانحراف منخفض في الفجوات.

تنبيه: الأسماء تصف **نمط النشاط** ولا تحكم على المتعلم. المتعلم الواحد قد يكون قريباً من حدود العنقود، ولا يعني الانتماء إلى عنقود شيئاً عن نتيجته.

### 4.5 توزيع درجة الخطر النسبية

مدرج من عشرة أعمدة يعرض عدد المتعلمين حسب درجة الخطر النسبية من 0 إلى 1، والعتبة هي الخط المتقطع الأحمر عند 0.46. وتُعرّف الدرجة هكذا:

> **درجة الخطر النسبية:** ناتج انحدار لوجستي (L2) على ملامح السلوك في السجل (الأيام النشطة، انتظام الفجوات، أول وصول، حصص أنواع النشاط) حتى أقرب قطع (اليوم 28 أو 56 أو 112)، مدرَّبة على العروض الثمانية الأخرى من 2013 لتمييز من انتهى بـ«رسوب أو انسحاب» عمّن انتهى بـ«نجاح أو امتياز». هي غير معايَرة: ليست احتمالاً، وتصلح لترتيب الأولوية فقط، وللمدرّس وحده ولا تغيّر التوصيات.

![الشكل 6: لوحة المدرّس، الجزء الثاني: توزيع الخطر وملامح السلوك وتغطية التوصيات](deliverables/05-user-guide/screenshots/live-05-instructor-desktop-b.png){width=100%}

قراءة المدرج بحذر:

- **الأعمدة فوق العتبة** مميّزة بلون دافئ وإطار داكن، والعمود الذي تقطعه العتبة يحمل الخط المتقطع. التمييز بالإطار والخط، لا باللون وحده.
- **الدرجة غير معايَرة.** أي أن 0.8 لا تعني أن 80% من أصحاب هذه الدرجة سينسحبون أو يرسبون. ترتيب المتعلمين بينهم أنفع من القيمة نفسها.
- **العتبة مأخوذة من تقييم Youden على عروض 2013**، وقد تختلف الصورة في عروض أخرى.
- **لا تستخدم المدرج لتحديد من يُتابَع أو يُعاقَب أو يُصنَّف.** المدرج أداة لفهم توزيع العرض، لا لإصدار أحكام فردية.

تحت المدرج: «درجة الخطر النسبية غير المعايَرة (لا حكم): الخط المتقطع والإطار الداكن يميّزان ما فوق العتبة لا اللون وحده.»

### 4.6 ملامح السلوك

ستة ملامح لجميع المتعلمين النشطين (أي من لهم يوم نشط واحد على الأقل)، كل منها بوسيط ونطاق ربيعي (بين الربيع الأول والثالث). الملامح في اللقطة:

- **الأيام النشطة:** وسيط 37 يوماً.
- **يوم أول وصول:** وسيط -16، أي قبل بداية العرض بـ16 يوماً.
- **انحراف الفجوات:** انحراف معياري لأيام الفجوات بين النشاط، وسيطه 1.98 يوماً.
- **حصة نشاط quiz:** وسيط 11.34%.
- **الالتزام بالمواعيد:** وسيط 100%.
- **متوسط الدرجات:** وسيط 79.2 درجة.

تُعرض القيم نفسها لكل متعلم في درج ملف المتعلم، مقابل وسيط العرض (القسم 4.9). الملامح **وصفية**. فهي ترسم صورة للعرض، ولا تقيس شيئاً عن جودة التعليم.

### 4.7 تغطية التوصيات

يجيب القسم عن سؤال: **كم من الكتالوج يصل إلى قوائم التوصيات؟** العبارة في أعلاه تقول مثلاً: «غطّت التوصيات 98 من 254 مورداً (Coverage@10 = 0.39)». والرسم أسفل ذلك يقارن لكل نوع من الموارد حصته في الكتالوج وحصته في التوصيات.

تغطية منخفضة تعني أن التوصيات تتركز في عدد محدود من الموارد الشائعة، وهذا يقلل التنوع ويزيد من الانحياز نحو الأكثر شيوعاً. والتغطية العالية ليست بالضرورة أفضل، فهي تعكس الجودة فقط حين يقترن بالدقة.

### 4.8 جدول المتعلمين

الجدول بعنوان «المتعلمون (مرتبون بدرجة الخطر النسبية تنازلياً)». أعمدته:

| العمود | المعنى |
|---|---|
| التسجيل | معرّف التسجيل |
| العنقود | العنقود السلوكي، بنقطة ملونة |
| الأيام النشطة | عدد أيام النشاط حتى اليوم t |
| آخر وصول | يوم آخر دخول للمقرر، مرقّماً من بداية العرض. «—» تعني لا وصول |
| الالتزام | عدد التسليمات في موعدها من إجمالي التقييمات المستحقة حتى اليوم t، بصيغة «x/y» |
| درجة الخطر النسبية | شريط ورقم (مقرّب) |

**الفرز:** اضغط عنوان العمود للفرز، ويظهر السهم على العمود المرتب. الأعمدة القابلة للفرز: التسجيل، والعنقود، والأيام النشطة، وآخر وصول، والالتزام، ودرجة الخطر النسبية.

**التصفية:** ثلاثة أزرار فوق الجدول: «الكل»، و«≥ العتبة» (المتعلمون فوق عتبة Youden)، و«بلا نشاط 14 يوماً».

تنبيه: الجدول يحمّل **100 متعلم** كحد أقصى في الصفحة. والتصفية «بلا نشاط 14 يوماً» تعمل على هذه الصفحة المحمّلة فقط، لا على العرض كله. إن كانت لديك حاجة للعرض كله فتحقق من عدد الصفوف الكلي قبل الاستنتاج.

**لوحة المفاتيح:** ↑ و↓ للتنقل بين الصفوف، وEnter لفتح ملف المتعلم. تلميح فوق الجدول يذكر ذلك.

![الشكل 7: ملف المتعلم، الدرج الجانبي، فوق جدول المتعلمين](deliverables/05-user-guide/screenshots/live-06-instructor-drawer-desktop.png){width=100%}

### 4.9 ملف المتعلم

عند فتح صف يظهر درج جانبي باسم «ملف المتعلم». محتواه:

1. **العنقود** مع وصفه، و**درجة الخطر النسبية** مع قطعها (مثلاً «قطع اليوم 56») وعتبتها.
2. **عوامل الدرجة (w·z):** أشرطة أفقية لكل ملمح، يساوي طولها مساهمة الملمح. الموجب يرفع الدرجة، والسالب يخفضها. يُكتب تحت الشريط: «الموجب يرفع الدرجة والسالب يخفضها؛ درجة نسبية غير معايَرة لترتيب الأولويات، لا حكم.»
3. **ملامح المتعلم مقابل الوسيط:** جدول بالقيمة والوسيط وقيمة z لكل ملمح. قيمة z تعني كم يبعد المتعلم عن الوسيط بوحدات الانحراف المعياري.
4. **أفضل 3 توصيات حالية:** نفس التوصيات التي يراها المتعلم عند اليوم t، لكي يستطيع المدرّس أن يرى ما يُقترح عليه.

**المتعلم الذي انسحب قبل القطع:** يظهر الدرج بعبارة «انسحب قبل القطع» بلا درجة، ولا تُحسب له درجة خطر.

يُغلق الدرج بزر × أو Esc، ويعود التركيز إلى الصف. الدرج يبدأ من يمين الشاشة لأن الصفحة من اليمين إلى اليسار.

### 4.10 القيود الأخلاقية والمنهجية

1. **لا تحكم على الطالب بالدرجة.** الدرجة غير معايَرة، والنموذج دُرّب على عروض أخرى، والنتائج توضيحية. لا تستعمل الجدول أو المدرج لتصنيف الطلاب أو لتحديد من يُستبعد أو يُعاقَب.
2. **لا تستعمل التسميات كأحكام.** العنقود وصف لنمط نشاط في لحظة معينة، لا صفة دائمة للطالب.
3. **لا سمات حساسة.** لا تدخل الجنس والإعاقة والمنطقة والعمر والمستوى التعليمي والدخل في أي نموذج، ولا تظهر في أي شاشة (D-21). تُستعمل في تحليل الإنصاف في التجربة وحده.
4. **البيانات مجهولة.** المعرّفات أرقام من البيانات، والنظام لا يعرف أسماء ولا هويات.
5. **لا حساب ولا صلاحيات.** أي شخص يصل إلى الرابط يرى اللوحة. لا تنشر الخادم خارج بيئة التجربة.
6. **العرض توضيحي.** اللوحة لعرض منهج النظام وحدوده، وليست أداة تشغيلية في مؤسسة.
7. **الإسناد:** بيانات OULAD مرخصة بموجب CC BY 4.0، وصفحة «عن النظام» تذكر ذلك.

## 5. الأسئلة الشائعة

**لماذا تتغير التوصيات عندما أغيّر اليوم؟**
لأن النظام يعيد الحساب عند اليوم المختار باستعمال تاريخ المتعلم حتى ذلك اليوم فقط. اليوم المتأخر يعني تاريخاً أطول، فتتغير الموارد المقترحة. وتتغير المعاملات الثقيلة أيضاً عند القطع 70 و126 و182، كما يظهر في شارة «تاريخ النموذج».

**لماذا لا تظهر درجة الخطر للمتعلم؟**
لأن الدرجة حكم على المتعلم وليست توصية له. ولم يُختبر أثرها على المتعلمين، فعرضها قد يغيّر سلوكه بطريقة لم تُدرس. الواجهة تفصل المتعلم عن أي وسم خطر أو عنقود، وهذا قرار مقصود في التصميم (D-22).

**ما الفرق بين اليوم و«لقطة العناقيد» و«نقطة التنقل السريع»؟**
اليوم هو ما تختاره أنت، والتوصيات تُحسب عنده دائماً (شريط السياق يقول «الحساب عند اليوم t نفسه»). «نقطة التنقل السريع» علامة على الشريط بفواصل 14 يوماً، تُستعمل للتنقل ولا تغيّر الحساب. «لقطة العناقيد» هي اليوم 56 الذي تُحسب عنده العناقيد مرة واحدة، وتظهر في سطر العناقيد بالعبارة «لقطة العناقيد: اليوم 56».

**لماذا عروض 2014 مقفلة؟**
لأنها مجموعة التأكيد. تبقى مغلقة حتى يُجمَّد النموذج، ثم يُشغَّل التأكيد مرة واحدة ويُنشر. فتجربة التأكيد لم يرها أحد قبل التجميد، وهذا ما يحمي صدقية النتيجة. يرد الخادم على أي عرض 2014 قبل النشر بالخطأ 409 `confirmatory_locked`.

**هل الأرقام في الواجهة نتائج بحثية؟**
لا. الأرقام في الواجهة للعرض والتوضيح فقط (D-49). النتائج البحثية تأتي من خط التجارب الأوفلاين في مجلد `results/`، بتقارير منفصلة. وأرقام الواجهة لا تُستخرج منها أي مقاييس تقييم.

**هل يجمع النظام بيانات المتعلمين الحاليين؟**
لا. النظام لا يجمع أي بيانات حيّة. يعمل على بيانات تاريخية محفوظة فقط.

**هل أستطيع الدخول كمتعلم أو كمدرّس بحساب؟**
لا. النظام لا يملك حسابات ولا تسجيل دخول. الدور يُختار من شريط التنقل، وتقتصر الفروق على المسارات والعقود وليس على صلاحيات الوصول.

**لماذا تظهر رسالة «لا مكوّن ثقيل قبل اليوم 70»؟**
لأن النموذجين الثقيلين (WRMF وGRU-lite) لم يكونا قد دُرّبا عند تلك الأيام في النظام. التوصيات في هذه الحالة من المكوّنات الخفيفة وحدها، وأوزانها أُعيدت معايرة لتبلغ الواحد.

**ما معنى شريط «عرض توضيحي بلا أمان وصول»؟**
يعني أن النظام تشغيل محلي للعرض والتجربة، ولا توجد فيه مصادقة. انظر القسم 1.4.

**لماذا لا تظهر السمات الحساسة (الجنس أو الإعاقة أو المنطقة)؟**
لأنها لا تدخل في أي نموذج، ولا تُعرض في أي شاشة (D-21). وتُستعمل في تحليل الإنصاف داخل التجربة فقط، وتُعرض نتائجه في الرسالة لا في الواجهة.

**ماذا تعني درجة الخطر النسبية 1 أو 0.98؟**
تعني أن المتعلم في أعلى ترتيب العرض حسب النموذج، وتستحق اهتماماً في المتابعة. ولا تعني أن الانسحاب أو الرسوب حتمي، ولا أن الرقم نسبة معايَرة. الدرجة للترتيب فقط.

**ماذا يعني «المهمة B»؟**
هي وضع يدخل فيه الموارد التي زارها المتعلم أيضاً في الترتيب. المهمة A (الافتراضية) تستبعد الموارد المزارة، وهي التي يبني عليها الهجين فرضياته في الرسالة.

**لماذا يظهر وسم «عناقيد غير مستقرة» مع ARI مرتفع؟**
لأن ARI يقيس ثبات البذور وحده، والاستقرار يشترط أيضاً أن يقع k ضمن أفضل اثنين في silhouette وDBI معاً. السبب مكتوب تحت الوسم، واعتبره تحذيراً بأن العناقيد قد تتغير، ولا تبنِ عليها قراراً.

**لماذا لا تظهر الأيام التي فيها صفر نشاط أو درجة في ملف المتعلم؟**
لأن الكود يحذف صفوف «أول وصول» و«متوسط الدرجات» عندما لا يوجد نشاط أو درجة، فالغياب هنا يعني أن القيمة غير موجودة، وليس صفراً.

**لماذا يتأخر أول طلب؟**
لأن أول طلب ليوم جديد يحسب التوصيات من البيانات، وهذا يستغرق نحو 10 ثوانٍ. الطلبات اللاحقة لليوم نفسه تأتي من الذاكرة فوراً. يقلل خيار `--warm` هذه المدة لليوم 75 وللعرض الافتراضي.

## 6. الملاحق

### 6.1 اختصارات لوحة المفاتيح

| المفتاح | المكان | الأثر |
|---|---|---|
| Tab وShift+Tab | كل الصفحة | التنقل بين عناصر التحكم |

| Home وEnd | شريط اليوم | الانتقال إلى الحدّين (اليوم 0 وآخر يوم) |

### 6.2 المسارات (للمطورين)

| المسار | الغرض |
|---|---|
| `/api/health` | الحالة وحالة التسخين |
| `/api/meta` | الإصدار وبصمة البيانات والقطوع |
| `/api/presentations` | قائمة العروض |
| `/api/registrations` | التسجيلات في عرض، مع بحث وترقيم |
| `/api/recommendations` | أفضل التوصيات عند يوم، مع المهمة A أو B |
| `/api/explanations/{registration}/{id_site}` | تفسير مورد محدد |
| `/api/learner/{registration}/history` | نشاط المتعلم حتى اليوم t |
| `/api/instructor/overview` | مؤشرات العرض وملامحه ومدرج الخطر والتغطية |
| `/api/instructor/clusters` | العناقيد والوصف والإسقاط |
| `/api/instructor/learners` | جدول المتعلمين مع الفرز والتصفية والترقيم |
| `/api/instructor/learner/{registration}` | ملف متعلم واحد |

أخطاء الواجهة البرمجية تأتي بصيغة `{"error":{"code","message","details"}}`. أهم الرموز: `day_before_first_snapshot`، و`day_out_of_range`، و`confirmatory_locked`، و`artifacts_missing`، و`instructor_disabled`.

### 6.3 مسرد المصطلحات

| المصطلح | المعنى |
|---|---|
| العرض (presentation) | دورة مقرر واحدة في البيانات، مثل `FFF_2013J` |
| التسجيل (registration) | مشاركة متعلم واحد في عرض واحد، ومعرّفها رقم الطالب مع العرض |
| اليوم t | اليوم المختار داخل العرض، ويبدأ من 0 |
| لقطة العناقيد | اليوم 56 الذي تُحسب عنده العناقيد مرة واحدة |
| نقطة التنقل السريع | علامة على الشريط بفواصل 14 يوماً للتنقل فقط |
| قطع النموذج (cutoff) | الأيام 70 و126 و182 التي دُرّبت عندها المكوّنات الثقيلة |
| تاريخ النموذج (model cut) | القطع الذي استُعملت معاملاته للتوصية الحالية |
| الهجين (hybrid) | مزيج موزون من عدة مكوّنات للتوصية |
| Recent-Pop | مكوّن يرتّب الموارد حسب الشيوع الحديث |
| SKNN | مكوّن جيران قريبين مبني على تاريخ المتعلم |
| WRMF | تحليل مصفوفي للتفاعلات (مكوّن ثقيل) |
| GRU-lite | شبكة تكرارية خفيفة على تسلسل النشاط (مكوّن ثقيل) |
| شعبية الأنماط المشابهة | مكوّن يرتّب الموارد حسب شيوعها بين المتعلمين ذوي النمط المشابه (C7) |
