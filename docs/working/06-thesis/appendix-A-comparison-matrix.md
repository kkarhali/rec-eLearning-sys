# الملحق أ: مصفوفة المقارنة الكاملة للمراجع وأحكام مصداقيتها

يضم هذا الملحق مصفوفة المقارنة الكاملة للمراجع الثمانية والثلاثين التي حُلّلت في الفصل الثاني، وأحكام مصداقية أوعيتها، وملاحظات التحقق البيبليوغرافي. وقُسّمت المصفوفة إلى ثلاثة جداول يربط بينها رقم المرجع، لتُقرأ في عرض صفحة طولية: الجدول أ-1 للوعاء والمجال والبيانات والطريقة، والجدول أ-2 للإشارات والمقاييس وأفضل نتيجة، والجدول أ-3 لأهم قيد والصلة والمحور. ثم يعرض الجدول أ-4 أحكام المصداقية وأسبابها. والأرقام كلها كما أوردها المؤلفون.
